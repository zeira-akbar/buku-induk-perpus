Petunjuk Pemasangan & Hubungkan Google Spreadsheet

1. Pengaturan Webhook Google Apps Script (Spreadsheet Sync)

Masukkan Web App URL dari Google Apps Script untuk menghubungkan aplikasi ini secara langsung ke Google Sheets Anda:

Cara Menghubungkan ke Google Spreadsheet:

  1. Buka Google Sheets baru di akun Google Anda, beri nama "Buku Induk Perpustakaan".
  2. Klik menu Ekstensi → Apps Script.
  3. Hapus semua kode lama, lalu salin dan tempel (Paste) kode Apps Script di bawah ini:
// KODE GOOGLE APPS SCRIPT UNTUK BUKU INDUK PERPUSTAKAAN
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  
  if (rows.length <= 1) {
    return ContentService.createTextOutput(JSON.stringify({status: "success", books: []}))
      .setMimeType(ContentService.MimeType.JSON);
  }
  
  var books = [];
  for (var i = 1; i < rows.length; i++) {
    var r = rows[i];
    books.push({
      tanggal: r[1] ? String(r[1]) : "",
      noInduk: r[2] || "",
      judul: r[3] || "",
      pengarang: r[4] || "",
      penerbit: r[5] || "",
      tempatTerbit: r[6] || "",
      edisi: r[7] || "",
      cetakanTahun: r[8] || "",
      klasifikasi: r[9] || "",
      banyakBuku: r[10] || "(C1)",
      asalBuku: r[11] || "",
      keterangan: r[12] || "",
      bahasa: r[13] || "",
      hargaSatuan: r[14] || 0,
      tanggalTerima: r[15] ? String(r[15]) : "",
      isbn: r[16] ? String(r[16]) : "",
      fakultas: r[17] || ""
    });
  }
  
  return ContentService.createTextOutput(JSON.stringify({status: "success", books: books}))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  if (data.action === "syncAll") {
    sheet.clear();
    sheet.appendRow([
      "No", "Tanggal", "Nomor Induk", "Judul Buku", "Pengarang", "Penerbit",
      "Tempat Terbit", "Edisi", "Cetakan/Tahun", "Klasifikasi", "Banyak Buku",
      "Asal Buku", "Keterangan", "Bahasa", "Harga Satuan", "Tanggal Terima", "ISBN", "Fakultas"
    ]);
    
    data.books.forEach(function(b, idx) {
      sheet.appendRow([
        idx + 1, b.tanggal, b.noInduk, b.judul, b.pengarang, b.penerbit,
        b.tempatTerbit, b.edisi, b.cetakanTahun, b.klasifikasi, b.banyakBuku,
        b.asalBuku, b.keterangan, b.bahasa, b.hargaSatuan, b.tanggalTerima, b.isbn, b.fakultas
      ]);
    });
    return ContentService.createTextOutput(JSON.stringify({status: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

  2. Pilih type Web App. Set "Execute as": Me, dan "Who has access": Anyone (Siapa Saja).
  3. Klik Deploy, lalu salin Web App URL dan tempelkan ke kolom URL di atas.

Catatan Fitur Otomatisasi:

  • No Induk: Dimulai dari 1999 secara acuan standar perpustakaan, otomatis bertambah 2000, 2001, dst. setiap ada data baru.
  • Pencarian AI ISBN: Menggunakan Gemini AI dengan pencarian terhubung (Search Grounding) ke Perpusnas RI, katalog INLISLite, Google Books, dan repositori perpustakaan universitas seluruh Indonesia.
  • Multiple Eksemplar (C1..C7): Jika memasukkan Banyak Buku = 7, sistem secara otomatis menyimpan 7 entri eksemplar terpisah dengan penulisan format (C1, C2, C3, ..., C7) dan Nomor Induk berurutan.
